# FFmpeg Sidecar Provenance

Encore packages FFmpeg and FFprobe as local executable sidecars. The binaries
are generated by `npm run prepare:ffmpeg-sidecars`; they are intentionally
ignored by Git and are never checked into source control.

The FFmpeg executable and FFprobe executable are FFmpeg-family binaries. Their
distributed license obligations are not changed by the wrapper package's
license. Before any public signed release, retain the generated
`node_modules/ffmpeg-static/ffmpeg.LICENSE` notice with the release artifacts
and review the exact binary build configuration and redistribution terms.

## Reproducible setup

1. Run `npm install`.
2. Run `npm run prepare:ffmpeg-sidecars`.
3. Run `npm run check:ffmpeg-sidecars` to verify both generated binaries and
   print their versions.

On Apple Silicon the generated names are
`src-tauri/binaries/ffmpeg-aarch64-apple-darwin` and
`src-tauri/binaries/ffprobe-aarch64-apple-darwin`; Intel macOS uses the
`x86_64-apple-darwin` suffix. Tauri's `bundle.externalBin` configuration uses
the unsuffixed bases so its bundler selects the matching target binary.

Both Tauri `beforeDevCommand` and `beforeBuildCommand` run the preparation
script. The script refuses cross-target output because the npm artifacts are
host-specific; build that target on a matching macOS host instead.
